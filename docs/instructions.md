# Система команд виртуальной машины Заря
## Общие сведения
Виртуальная машина Заря использует стековую архитектуру с троичной логикой. Все операции выполняются над значениями в стеке, за исключением инструкций, которые явно работают с регистрами или памятью.

## Режимы адресации
Машина поддерживает следующие режимы адресации операндов:
1. Непосредственный (#value):
   ```asm
   PUSH #42    ; Положить число 42 в стек
   MOV R0, #5  ; Записать 5 в R0
   ```

2. Регистровый (Rn):
   ```asm
   PUSH R0     ; Положить значение из R0 в стек
   MOV R1, R0  ; Копировать из R0 в R1
   ```

3. Косвенный через регистр (@Rn):
   ```asm
   PUSH @R0    ; Положить значение из памяти по адресу в R0
   MOV R1, @R0 ; Загрузить в R1 значение из памяти по адресу в R0
   ```

## Псевдоинструкции
Псевдоинструкции предоставляют более удобный синтаксис для часто используемых операций. Каждая псевдоинструкция транслируется в последовательность базовых инструкций.

| Мнемоника | Операнды | Режимы адресации | Описание | Трансляция |
|-----------|----------|------------------|-----------|------------|
| MOV | 2 | Регистровый (Rn), Косвенный (@Rn) | Пересылка данных между регистрами | PUSH src; POP dst |
| INC | 1 | Регистровый (Rn) | Инкремент значения в регистре | PUSH reg; PUSH 1; ADD; POP reg |
| DEC | 1 | Регистровый (Rn) | Декремент значения в регистре | PUSH reg; PUSH 1; SUB; POP reg |
| PUSHR | 1 | Регистровый (Rn) | Положить значение регистра в стек | PUSH reg |
| POPR | 1 | Регистровый (Rn) | Снять значение со стека в регистр | POP reg |
| CLEAR | 1 | Непосредственный (#value) | Очистить N элементов стека | DROP × n |
| CMP | 2 | Непосредственный (#value), Регистровый (Rn), Косвенный (@Rn) | Сравнить два значения | PUSH a; PUSH b; SUB |
| TEST | 1 | Непосредственный (#value), Регистровый (Rn), Косвенный (@Rn) | Проверить биты значения | PUSH val; DUP; AND |

## Формат инструкций

Каждая инструкция состоит из одного или нескольких трайтов:
1. Опкод (1 трайт)
2. Операнды (0-2 трайта)

### Структура опкода
```
+-------------+----------------+
| Режим адр.  | Базовый опкод |
| (1 трит)    | (остальные)   |
+-------------+----------------+
```
